> [!TIP]
>
> 1) Installare Kodi sul proprio dispositivo





> [!CAUTION]
>
> Per un pieno funzionamento di kodi con tutte le sue  dipendenze corrette, scaricare  Kodi dal proprio sito seguendo i passaggi sotto riportati per i vari Sistemi Operativi



> [!IMPORTANT]
>
> Se Kodi è già pre installato e non si è certi che tale versione provenga dal suo sito, disinstallarlo e procedere seguendo i passaggi sotto riportati per i vari Sistemi Operativi



??? info "Kodi Per Windows"
       Installer per Windows

    * https://kodi.tv/download/windows/
    * Selezionare sezione "Raccomanded"
    * Scaricare Installer 32bit o 64bit (NON Windows Store)



??? info "Kodi per Android/AndroidTv"
       Installer per Android/AndroidTv

    * https://kodi.tv/download/android/
    * Selezionare sezione "Raccomanded"
    * Scaricare Installer ARMV7A32bit (AndroidTv fino V12) o ARMV8A64bit (Smartphone/Tablet/AndroidTv >14)



??? info "macOS"
       Installer per macOS 

    * https://kodi.tv/download/macos/
    * Selezionare sezione "Raccomanded"
    * Scaricare Installer Intel (x86_x64) ARM64



??? info "Kodi per Linux"
       Installer Flatpak 

    * https://flathub.org/en/apps/tv.kodi.Kodi
    * Premere pulsante "Install" o installare da proprio Store
    * Da terminale digitare:
      sudo flatpak install flathub tv.kodi.Kodi
